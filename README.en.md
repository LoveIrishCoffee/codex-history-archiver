# Codex History Archiver

An **unofficial Windows utility** for batch archiving and restoring local Codex conversations. Version: `0.1.0-preview`. The UI is currently in Simplified Chinese.

[中文使用说明](README.md) · [MIT license](LICENSE)

The utility runs an already-installed `codex.exe app-server --stdio` and uses native local archive APIs. It does not bundle Codex or patch the desktop app's archive button.

## Requirements and scope

- Windows 10 / 11 with .NET Framework 4.8.
- An existing Codex installation and local conversation directory.
- Native archive protocol verified with CLI `0.158.0-alpha.2.1` and desktop `26.924.2738.0`. Other versions are not yet verified; experimental API fields may change.
- Local user conversations only. Cloud ChatGPT conversations, subagents, and stale indexes with missing history files are excluded.

## Usage

1. Extract the Windows ZIP and run `CodexHistoryArchiver.exe` without administrator privileges.
2. Check the selected Codex executable and home directory in settings. The home defaults to `CODEX_HOME`, then the current user's `.codex`. Saved settings override these defaults; startup arguments override the current run only.
3. Let other tasks finish and fully quit the Codex desktop app, keeping this utility open.
4. Search, check conversations, and click the archive button. Review the confirmation before continuing.
5. Refresh to verify the result. Switch to the archived list to restore conversations.
6. Close the utility before reopening Codex.

Changing filters clears checked items. Project conversations are included; review their working directories. Stop finishes the current request and verification before ending the batch. An active writer causes a failure; an uncertain outcome stops the batch without automatic retry.

Optional startup paths:

```powershell
.\CodexHistoryArchiver.exe --home "D:\CodexData" --codex-exe "D:\Tools\Codex\codex.exe"
```

## Privacy and behavior

The client allowlists initialization, thread list/read, archive, and unarchive requests. Reads use `includeTurns: false`; it does not request conversation turns or send model requests. It does not directly edit the state database, rewrite history files, copy credentials, or clean up projects/worktrees.

Settings and logs are stored under `%LOCALAPPDATA%\CodexHistoryArchiver`. Logs contain timestamps, conversation IDs, actions, and outcomes, but no titles, bodies, credentials, or raw server errors. Do not publish your local logs or settings. The selected Codex subprocess uses its own configuration; this utility cannot guarantee that subprocess is fully offline.

## Build and test

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\run-tests.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\package.ps1
```

Builds use the Windows .NET Framework compiler without downloading dependencies. Output is in `dist`. Tests use a synthetic server and temporary directories, not real conversations. They verify client behavior, not compatibility with every Codex release. GitHub Actions builds and tests but does not automatically publish releases.

Publish only this standalone source project. Release archives and a SHA-256 manifest are generated by the packaging script. Mark the first GitHub release as a prerelease.
