# Changelog

## 0.1.0-preview — 2026-09-29

First standalone public preview candidate.

- Search and batch archive/restore of local user conversations.
- Confirmation, per-conversation verification, writer-lock handling, and stop between operations.
- Portable executable discovery and configurable paths.
- Local logs omit conversation titles and contents.
- Windows build, synthetic protocol tests, CI configuration, and reproducible packaging steps.

Compatibility is limited to the versions listed in the README. The utility does not repair the desktop app's built-in archive action.
